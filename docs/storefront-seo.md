# Storefront search rendering strategy

The Storefront is a static Angular client. Public page metadata and schema.org JSON-LD are set by the client after Angular starts; the public catalog and its localized product metadata load from Core. This preserves the API-only frontend boundary and avoids introducing a second server runtime into the optional Storefront deployment.

Google Search Central documents that Googlebot queues successful pages for rendering, runs their JavaScript in a headless Chromium, and uses the rendered HTML for indexing. It also documents JavaScript-generated JSON-LD as supported. This makes the current client-rendered metadata and product `ItemList` a supported Google Search path. Rendering can be delayed, and search engines that do not execute JavaScript may not see this metadata; Google recommends server-side or pre-rendering where broad crawler coverage or faster rendering is required. See [JavaScript SEO basics](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [JavaScript-generated structured data](https://developers.google.com/search/docs/appearance/structured-data/generate-structured-data-with-javascript), and [JavaScript search issues](https://developers.google.com/search/docs/crawling-indexing/javascript/fix-search-javascript).

Artio exposes `/sitemap.xml` and `/robots.txt` from Core. The sitemap lists the canonical public routes (`/`, `/shop`, `/bundles`) and published product details, and excludes account, cart, checkout and order flows. On `/shop`, the client inserts a schema.org `ItemList` with localized `Product` entries after product metadata and primary media are loaded. Each item links to a standalone `/products/{slug}?locale={locale}` page. The public API resolves the requested translation slug, then the English slug, then the base product slug; inactive and archived products are not exposed. Product pages load active variants and request their price from Core, then publish localized canonical/Open Graph metadata and a schema.org `Product` with an `Offer` when a current quote is available.

Before a public production launch, set `ARTIO_STOREFRONT_URL` to the public origin and verify the live rendered page with Google's Rich Results Test and Search Console URL Inspection. Product metadata remains client-rendered, so non-JavaScript crawler coverage and rendering latency retain the documented limitations; add pre-rendering or server-side rendering if broad crawler coverage or faster indexing becomes a release requirement.
