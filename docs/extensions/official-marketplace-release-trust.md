# Official Marketplace release trust, version 1

Official Marketplace installs use the server-side route `GET /api/v1/admin/extensions/marketplace/plugins/{pluginId}/releases/{version}/descriptor`. Core fetches Marketplace's signed envelope and returns the descriptor only after local verification. The existing `/manifest` route and direct manifest registration remain available for explicit custom/private plugin workflows; they do not establish official provenance.

Marketplace signs the RFC 8785 (JCS) canonical UTF-8 bytes of the descriptor object with Ed25519. The descriptor schema is shared in Marketplace at `marketplace-contract/release-descriptor-v1.schema.json`; its envelope is `signed-release-envelope-v1.schema.json`. The descriptor binds package/version, a JCS digest of the exact manifest object, the original manifest, and the complete set of digest-pinned public OCI main and sidecar images. Core verifies the descriptor route identity, manifest digest, image references and inventory, key identifier, and Ed25519 signature before passing the verified descriptor to official installation logic.

Set `ARTIO_MARKETPLACE_TRUSTED_KEYS` to comma-separated `key-id=base64url-X509-public-key` entries. A missing or unknown key fails closed. The public key is an Ed25519 SubjectPublicKeyInfo byte sequence encoded with unpadded base64url. Core never stores or receives the signing private key. Rotate by configuring old and new key IDs concurrently in Marketplace and Core, signing new releases with the new key, verifying the rollout, then removing the old key. Do not rewrite signed historical releases during key rotation.

The Marketplace signing key is held in a protected CI environment; a separate hash-configured signature-ingest token protects submission. The descriptor endpoint is unavailable until Marketplace verifies and stores the signature against the immutable published release. This trust gate does not replace compatibility validation, trusted registry policy, local authorization, installation orchestration, or runtime security. Unsigned Marketplace content must not be treated as official.
