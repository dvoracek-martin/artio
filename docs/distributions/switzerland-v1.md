# Switzerland distribution manifest v1

Artio Core packages the immutable `switzerland-v1` regional defaults at `artio-rest-api/src/main/resources/distributions/switzerland-v1.json`. The public, versioned read-only API exposes the installed catalog at `GET /api/v1/public/distributions` and one manifest at `GET /api/v1/public/distributions/{id}`. The unversioned `/api` alias remains available through the normal API versioning filter.

The manifest defines CH, CHF, `de-CH`, the `de`, `fr`, `it`, and `en` language set, and `Europe/Zurich`. These values are discoverable defaults; they do not silently overwrite merchant settings. Core validates each packaged manifest during application startup: supported schema version, unique versioned identifier, ISO country/currency, locale, IANA time zone, bounded unique languages, and unique well-formed plugin recommendation IDs.

The manifest currently recommends optional `payments.stripe`, `payments.twint`, and `shipping.swiss-post` integrations. It does not contain images or digests because the reference provider images have not been published. On first-run completion, Artio records each recommendation as `WAITING_FOR_RELEASE` or records the lifecycle of an already registered plugin. SUPERADMIN can review these states under System Settings; registration, configuration, installation, retry, and explicit enable/disable remain in Plugin Manager. The status endpoint is `GET /api/v1/admin/system/distribution/plugins`; refresh is an explicit `POST /api/v1/admin/system/distribution/plugins/refresh`. A published release remains necessary before any recommendation can be installed. Artio does not auto-enable provider plugins or claim that unavailable releases were installed.
