# Backoffice product search v1

The admin catalog uses a bounded database query instead of downloading the entire catalog and filtering only in the browser. `GET /api/v1/admin/catalog/products` returns `{ items, total, page, size }`, with page size 1–100 and offset bounded to 100,000 pages. Optional `q` matches product name, SKU or ID; `state` accepts `ALL`, `ACTIVE` or `INACTIVE`; `brandId` and `categoryId` are UUID filters. Sort is allowlisted (`name`, `sku`, `createdAt`, `updatedAt`) and direction is `asc` or `desc`; ID is a stable tie-breaker. Search text is length-bounded and SQL wildcard characters are escaped.

The Backoffice Products view offers search, active/draft state, brand, category, sort, direction and previous/next page controls. Variant lists are fetched only for the current page. The endpoint is protected by the admin API security matcher.
